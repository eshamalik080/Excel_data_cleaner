# Excel Data Cleaning & Report Generator (Python)

This project automates cleans data in Excel and generate reports using Python.

## Features
  Removes duplicate rows
  Handles missing values
  Generates summary reports
  Creates sales charts
  Outputs clean Excel files automatically

## Tools Used
- Python
- Pandas
- Matplotlib
- OpenPyXL

## How to Run
1. Place your Excel file as `input_data.xlsx`
2. Run: `python excel_cleaner.py`
3. Output will be saved in the `output` folder
